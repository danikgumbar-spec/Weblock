Yes. {brand} is free to use. An account is free too — you only need one for the AI assistant, live collaboration and community templates.

Download the archive, extract it with WinRAR or 7-Zip, then run the app.

New apps that are not code-signed yet can trigger Windows SmartScreen. If you downloaded the file from this page, choose “More info”, then “Run anyway”.
